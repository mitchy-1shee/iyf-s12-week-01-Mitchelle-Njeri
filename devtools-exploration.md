## HTMLTags

• <html> -Defines the root of the document
• <head> -Contains metadata and document information
• <title> -Sets the title shown on the browser tab
• <meta> -Specifies character encoding and viewport settings
• <style> -Contains the internal CSS styling for the page layouts
• <body> -Contains the visible page content
• <div> -Acts as a structural container for the text
• <h1> -Defines the main heading
• <p> -Defines the paragraphs of text
• <a> -Creates the hyperlink to the documentation


  ## Page Title 
  
  It's an element that defines the text shown on a browser's title bar or tab. 
  It is created using the <title> tag and must always live inside the <head> block of the HTML document.
