## HTML Tags

<!DOCTYPE html> – Declares the document type as HTML5.

<html> – The root element that wraps all content on the page.

<head> – Contains page metadata, scripts, and stylesheets.

<title> – Sets the browser tab title for the webpage.

<body> – Contains the visible content of the web page.

<meta> – Defines metadata like character encoding, keywords, and viewport settings.

<link> – Connects external resources (like CSS stylesheets) to the document.

<style> – Holds internal CSS rules directly within the HTML.

<script> – Embeds or points  executable JavaScript.


## Semantic Layout & Sections

• <header> – Defines the introductory section or top navigation area.

• <nav> – Groups navigation links together.

• <main> – Specifies the primary, unique content of the document.

• <section> – Groups related content into thematic chapters or sections.

• <article> – Wraps independent, self-contained content (like a blog post).

• <aside> – Marks content aside from main text (like a sidebar).

• <footer> – Defines the bottom section containing copyright or contact info.

• <div> – A generic block-level container used for CSS styling layout.

• <span> – A generic inline container used to style specific words or text segments.


## Text & Formatting.


• <h1> to <h6> – Create structural headings from highest (h1) to lowest (h6) importance.

• <p> – Defines a paragraph of text.

• <br> – Inserts a single line break (self-closing).

• <hr> – Creates a horizontal line/rule to separate content.

• <strong> – Indicates strong importance, bolding the text semantically.

• <b> – Bolds text visually without adding semantic importance.

• <em> – Emphasizes text, italicizing it semantically.

• <i> – Italicizes text visually for technical terms or idiomatic phrases.

• <mark> – Highlights or marks text with a background color.

• <del> – Represents deleted text (strikethrough).

• <ins> – Represents inserted text (underlined).

• <sub> / <sup> – Formats text as subscript or superscript.

• <blockquote> – Indicates a block quotation from an external source.


## Links & Multimedia


• <a> – Creates hyperlinks via the href attribute.

• <img> – Embeds an image on the page via the src attribute (self-closing).

• <audio> – Embeds audio player content.

• <video> – Embeds video player content.

• <iframe> – Embeds another HTML page inside the current document.


## Lists & Tables


• <ul> – Creates an unordered (bulleted) list.

• <ol> – Creates an ordered (numbered) list.

• <li> – Defines a single list item inside <ul> or <ol>.

• <table> – Declares a data table.

• <tr> – Defines a table row.

• <th> – Defines a table header cell (bold and centered by default).

• <td> – Defines a standard table data cell.


## Forms & User Inputs

<form> – Acts as a container for collection fields.

<input> – Creates versatile interactive controls (text boxes, radio buttons, checkboxes via type).

<textarea> – Generates a multi-line text input control.

<label> – Pairs a text description to an input field for accessibility.

<select> – Creates a drop-down selection list.

<option> – Defines individual items within a <select> drop-down list.

<button> – Creates a clickable button control.
